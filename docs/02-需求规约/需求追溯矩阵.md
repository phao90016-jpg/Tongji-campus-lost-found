## 4. 维护约定

- 新增需求：先加 [SRS](SRS-v1.0.md) 条目，再在本表加行，再补用例与测试
- 新增测试：必须在本表登记其来源需求，否则视为孤儿用例
- 每次增量发布前跑一次覆盖率自查，把结果贴到该次迭代回顾里
- 本表与 [测试用例库](../05-测试/测试用例库.md) 的 TC 编号必须一致，改名走变更流程
