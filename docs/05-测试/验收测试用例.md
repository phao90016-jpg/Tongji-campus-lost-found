# 验收测试用例

> 交付物｜对应单元：7 测试｜检查点：期末｜负责人：测试 / 质量工程师｜状态：**模板**
> 验收判定依据：[SRS v1.0](../02-需求规约/SRS-v1.0.md) §7 验收标准（ACC-01 ~ ACC-16）

## 1. 验收场景设计原则

- **按角色写，不按接口写**：验收测试模拟"人怎么用"，而不是"接口能不能通"
- **每条场景有明确判定依据**：能指回 ACC 编号
- **数据可预置**：每条场景写清准备数据，保证可重复执行
- **异常场景也要验收**：冒领、越权、过期、并发是真实发生的
