# 校园失物招领与认领审核系统

软件工程课程设计（CST3619 / 420146）。

系统帮助学生发布失物或招领信息，让失主提交认领申请，由拾取者和管理员完成审核，并记录最终的领取确认。

## 业务主干

1. 拾取者发布招领信息，设置核验问题和答案。
2. 失主检索物品，提交认领理由、答案和可选材料。
3. 拾取者初审申请，给出建议和理由。
4. 管理员终审，决定通过或驳回。
5. 终审通过后，获准领取人在拿到实物后确认领取。

同一件招领最多有一条进行中的认领申请。手机号默认脱敏，原图只向有业务权限的人开放，敏感操作写审计日志。

## 本地运行

后端：

```powershell
cd src/backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
Copy-Item .env.example .env
pytest -q
uvicorn app.main:app --reload
```

前端：

```powershell
cd src/frontend
npm install
npm run dev
```

后端当前提供 `GET /health` 和 `GET /api/v1/meta`。业务接口尚未实现。
