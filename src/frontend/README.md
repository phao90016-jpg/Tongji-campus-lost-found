# 前端（Vue 3 + TypeScript + Vite）

## 目录

```
src/
├── main.ts        # 入口
├── App.vue        # 根组件（骨架期仅占位）
├── router/        # 路由
├── api/           # 接口封装（组件不直接发请求）
├── stores/        # Pinia 状态
├── components/    # 可复用组件
└── views/         # 页面
```

## 计划页面（v0.1 起交付）

| 路由 | 页面 | 角色 | 对应用例 |
|---|---|---|---|
| `/login` | 登录 | 匿名 | UC-01 |
| `/` | 发布列表与检索 | 全部 | UC-10、UC-11 |
| `/items/:id` | 发布详情与申请入口 | 全部 | UC-12、UC-15 |
| `/publish` | 发布失物 / 招领 | 学生、拾取者 | UC-05、UC-06、UC-09 |
| `/mine` | 我的发布与申请 | 学生、拾取者 | UC-08、UC-16 |
| `/claims/inbox` | 待初审（拾取者） | 拾取者 | UC-17 |
| `/handover/:id` | 交接核销 | 双方 | UC-19 |
| `/admin/workbench` | 需跟进筛选（v0.1）；完整工作台（v0.2） | 值班老师、分派案件的志愿者 | UC-32 |
| `/admin/items` | 终审队列 | 审核员 | UC-18 |
| `/admin/reports` | 举报处置 | 审核员 | UC-23 |
| `/admin/stats` | 统计看板 | 审核员、管理员 | UC-30 |
| `/admin/users` | 用户与角色 | 管理员 | UC-33 |
| `/admin/settings` | 分类 / 地点 / 配置 | 管理员 | UC-34 |

## 本地开发

```bash
npm install
npm run dev          # 默认 http://localhost:5173，/api 代理到 :8000
```

## 约定

- 接口统一走 `src/api/`，组件不直接发请求
- 页面按角色分区：公共端 `/`，审核后台 `/admin`
- **前端隐藏按钮不算权限控制**：越权判定必须在后端，前端只做展示层隐藏
- 403 统一提示"无权访问"，不区分"不存在"与"无权限"
- 手机号等敏感字段由后端脱敏，前端不做二次拼接

> 骨架期仅含占位页面，业务页面自 v0.1 起按 Issue 交付。
